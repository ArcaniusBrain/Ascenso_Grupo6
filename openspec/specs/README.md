# Specs por capacidad

Aquí vive la especificación vigente de cada capacidad del sistema (`<capacidad>/spec.md`). **No se edita a mano:** las specs nacen y cambian al archivar un cambio de `../changes/` (`openspec archive <cambio>`). La única excepción es la sección `## Purpose` de una spec.

Los nombres de capacidad permitidos están en el catálogo de `../config.yaml` y en [`docs/guia-openspec.md`](../../docs/guia-openspec.md).
